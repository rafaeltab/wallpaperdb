# GLOSSARY.md Format

`GLOSSARY.md` defines the teaching workspace's terminology. Use it in explainers, exercises, and learning records.

## Structure

```md
# {Topic} Glossary

{One or two sentences describing the topic.}

## Terms

**RPE (Rate of Perceived Exertion)**:
A 1–10 self-rating of how hard a set felt, where 10 is failure and 8 means two reps left.
_Avoid_: Effort score, intensity rating
```

## Rules

- Add terms only after the user demonstrates they can use them correctly.
- Pick one term per concept and list aliases to avoid.
- Define what the term is in one or two sentences, using existing glossary terms.
- Group terms under subheadings when natural clusters emerge.
- Resolve ambiguous usage explicitly, such as excluding warm-ups from "set."
- Revise definitions as understanding deepens.
