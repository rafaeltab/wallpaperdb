title: Asset Effect migration
description: Delivery catalog transactions, replay, and scoped resource ownership.
---

Asset adopted application-owned Effect ports and scoped adapter layers. A PostgreSQL transaction accepts event occurrences, catalog changes, and availability publication intent together. An outbox publishes with stable CloudEvent identities and waits for JetStream acknowledgement. Replay resolves ambiguous publication without requiring a cross-system transaction.

The [context decision](https://github.com/rafaeltab/wallpaperdb/blob/main/apps/asset/docs/adr/0001-replay-safe-delivery-catalog.md) records catalog ordering, resource bounds, and recovery. Its amendments distinguish the original immutable-target and User-authorized picture design from the target Asset/Source model.

For migration and exhausted-consumer recovery, use the [Asset upgrade procedure](/docs/guides/service-upgrades#asset).
