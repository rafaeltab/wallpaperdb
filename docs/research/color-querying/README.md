# Color-query reference

This research defines the numerical reference used when changing color extraction or ranking. [ADR 0006](../../adr/0006-use-precomputed-color-utilities-with-three-quality-levels.md) owns the accepted behavior and integration decisions.

## Reference capabilities

- [Selected method](METHOD.md) explains overlapping color measurements, quality preferences, and scoring mathematics.
- [Evidence and limits](EVIDENCE.md) distinguishes preference judgments, ranking parity, and measured capacity. The complete three-setting bank has no production capacity qualification.

The [preserved prototype](https://github.com/rafaeltab/wallpaperdb/tree/30edcb2a61e6c4cc915a61807210a3ab5e924d96/experiments/color-search-benchmark) contains runnable sources, evaluation cases, judgments, and historical findings. Use that pinned archive to reproduce comparisons. Prototype-local service URLs are not maintained repository workflows.
