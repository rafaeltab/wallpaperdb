# MISSION.md Format

`MISSION.md` lives at the workspace root and guides teaching decisions.

## Template

```md
# Mission: {Topic}

## Why
{1–3 sentences describing the concrete outcome in the user's life or work.}

## Success looks like
- {A specific, observable ability}

## Constraints
- {Time, budget, commitments, or learning preferences}

## Out of scope
- {Adjacent topics the user excludes for now}
```

## Rules

- Keep one mission per workspace; use separate workspaces for unrelated topics.
- Interview the user until the goal is concrete before writing it.
- Keep the mission under a screen and revise when the goal changes, following [the confirmation requirement](SKILL.md#the-mission).
