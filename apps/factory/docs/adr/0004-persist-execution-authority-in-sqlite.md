# Persist execution authority in SQLite

Factory jobs, planner associations and stack journals use one local SQLite database through Drizzle so claims, revision checks and legacy import can use database transactions without adding a separate database service. This supersedes only the file-storage mechanism in [ADR 0002](0002-preserve-claims-across-uncertain-external-outcomes.md), preserving immutable record identities, durable responsibility before external effects, and reconciliation of uncertain outcomes without automatic duplicate launches or deliveries. The [schema](../../src/platform/schema.ts) and [persistence implementation](../../src/platform/durable.ts) retain the existing capability contracts; the [host operations guide](../../OPERATIONS.md#upgrade-and-recovery) owns migration, backup and rollback procedures, including preservation of original legacy files and the restriction against restoring stale JSON after SQLite advances.
