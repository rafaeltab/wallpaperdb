# Coverage runtime

Private tooling for collecting source-bound test coverage and merging verified tier receipts. Repository orchestration supplies the checkout location and application policy.

## Capabilities

The runtime retains raw measurements and generated mock source bytes, audits explicitly configured branch estimates, and publishes JSON, LCOV and HTML reports. Receipt merging verifies the selected tier inventory, checkout identity and original source hashes before publishing an aggregate.

Commands and hooks execute compiled ESM. Incremental builds keep active preloads available during nested workspace builds. Application execution adapters and the pinned Factory estimate sites belong to repository configuration. See the [coverage guide](../../docs/coverage.md) for collection and qualification limits.
