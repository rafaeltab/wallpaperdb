---
title: Effect in the Gateway
description: Effect services, dependency inversion, and scoped execution.
---

Gateway adopted Effect 4 services and layers to make dependencies explicit and own connections, request fibers, and background consumers. Typed `Context.Service` keys replaced constructor-only injection and `Symbol.for` tokens. One managed runtime bridges Fastify and Mercurius; scoped shutdown drains or interrupts work before closing dependencies, including after partial startup.

Normal outcomes remain result values. Tagged Effect errors represent technical failures and are translated at transport boundaries. Tests use the matching `@effect/vitest` adapter on Vitest 5, with a controlled clock for capability tests and `it.live` for network lifecycles.

The [context decision](https://github.com/rafaeltab/wallpaperdb/blob/main/apps/gateway/docs/adr/0002-effect-services-and-owned-lifetimes.md) records composition, testing, and compatibility details. Its historical quota bypass was replaced by the [gateway admission contract](/docs/guides/gateway-admission).
