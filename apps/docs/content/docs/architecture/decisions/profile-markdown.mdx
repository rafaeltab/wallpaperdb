---
title: Shared Biography Markdown policy
description: One policy for authored Markdown, owned wallpaper embeds, and safe rendering.
---

User and Web share `@wallpaperdb/profile-markdown` so server validation and React rendering accept the same syntax and URLs. User persists authored Markdown, never generated HTML. Web renders with React Markdown, GFM, the shared remark plugin, and sanitization.

The policy rejects raw HTML, ordinary image URLs, and unsafe or credential-bearing destinations. External links require HTTPS and show a hostname warning before navigation. Wallpaper embeds use `![Alt text](wallpaper:<wallpaper-id>)`; User checks the author's ownership against an event-fed projection. Projection lag can briefly reject a new upload. Deletion or unpublication must update ownership and embed availability together.

See the [shared policy decision](https://github.com/rafaeltab/wallpaperdb/blob/main/docs/adr/0005-share-the-profile-markdown-policy.md) and [profile editing guide](/docs/guides/profile-editing).
