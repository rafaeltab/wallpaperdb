---
title: Variant generator Effect migration
description: Replay-safe publication and bounded native image work.
---

Variant Generator adopted Effect services and scoped adapters so input acknowledgement follows durable storage and publication of every selected output. Previously, publication failures could leave an acknowledged batch incomplete. Stable object keys and event identities make retries safe across independent S3 and JetStream operations. Exhausted input requires durable quarantine before acknowledgement.

Native encoding runs in a child process because a Promise timeout cannot stop libvips. Interruption kills and reaps the process before releasing its permit. This adds process overhead in exchange for enforceable deadlines and shutdown.

The [context decision](https://github.com/rafaeltab/wallpaperdb/blob/main/apps/variant-generator/docs/adr/0001-replay-safe-variant-generation.md) records processing limits, immutable output metadata, and replay formats. Its amendments move generation into Asset and replace the original preset-selection policy in the target design.

Use the [worker upgrade procedure](/docs/guides/service-upgrades#enrichment-workers) and [shared quarantine replay procedure](/docs/guides/service-upgrades#quarantine-replay) for retained work.
