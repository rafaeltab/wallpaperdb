The Tags Service is currently a minimal shell that reserves runtime wiring for future tagging work without committing to a domain interface or storage model yet.

The shell uses Effect for dependency composition, request execution, and scoped resource cleanup. There are no tag operations, publications, or consumers.

## Quick Start

```bash
# Start infrastructure
make infra-start

# Run tags service in development mode
make dev PACKAGE=tags

# The service starts on http://localhost:3008
```

## Implemented Today

- Fastify operational endpoints with generated OpenAPI
- PostgreSQL and NATS connection lifecycle management
- Health and readiness endpoints only

## Current API

### Health

- `GET /health`
- `GET /ready`

Healthy and degraded health results return HTTP 200. Unhealthy and shutdown results return HTTP 503 with Problem Details and a `healthStatus` extension. Readiness reflects completed startup and shutdown state, independently of dependency health.

PostgreSQL connects lazily, while NATS connects before the listener accepts work. Health probes cancel PostgreSQL work at their five-second deadline. Shutdown allows requests five seconds to finish before interrupting remaining work and releasing resources. Telemetry initializes before external clients load and flushes during shutdown.

No domain routes are published yet, and no tags-specific schema is defined. The shell is intentionally limited to operational endpoints until the tagging model is defined.

## Configuration

```bash
PORT=3008
NODE_ENV=development
DATABASE_URL=postgresql://wallpaperdb:wallpaperdb@localhost:5432/wallpaperdb_tags
NATS_URL=nats://localhost:4222
NATS_STREAM=WALLPAPER
OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4318
OTEL_SERVICE_NAME=tags
```

## Validation

```bash
make check PACKAGE=tags
make test-unit PACKAGE=tags
make test-integration PACKAGE=tags
make check-crap PACKAGE=tags CRAP_THRESHOLD=30
make run PACKAGE=tags SCRIPT=gen:swagger
```

Integration tests use real PostgreSQL and NATS. They also exercise the built Node entrypoint and the production telemetry mechanism. No tagging feature exists to demonstrate in the wallpaper UI.
