## Public interface

`@wallpaperdb/events` and `@wallpaperdb/events/schemas` export Zod schemas, inferred event types, and NATS subject names. They cover wallpaper uploads, generated and available variants, extracted colors, and public Profile snapshots.

```typescript
import { WallpaperUploadedEventSchema } from "@wallpaperdb/events/schemas";

const parsed = WallpaperUploadedEventSchema.safeParse(payload);
if (parsed.success) {
  // Translate the public contract into this application's local input.
}
```

Schema parsing validates the payload. A driving adapter also validates the CloudEvents envelope, including binary headers, and preserves the source and ID as the occurrence identity. Correlation, causation, trace identity, and broker subjects have separate meanings.

## Delivery ownership

Each application owns its Effect-based publisher and consumer adapters. The package does not export broker runners. The former `BaseEventPublisher` and `BaseEventConsumer` classes were removed because no application uses them and their default behavior did not provide the required delivery guarantees.

Publishers preserve occurrence identity on retry and await JetStream PubAck before marking an outbox entry published. Consumers acknowledge only completed or durably accepted work. They use bounded delayed retries and confirm durable quarantine before terminating invalid or exhausted messages. Quarantine retains the original payload and envelope for replay.

The authoritative requirements are the repository's distributed-interaction and NATS coding guidelines. See the [NATS infrastructure page](/docs/infrastructure/nats) for local broker operations.
