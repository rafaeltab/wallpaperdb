# Continue existing work

After the main workflow's clean-worktree and fetched-trunk checks, fetch the actual remote heads and verify their recorded published tips, PR identities, and parent relationships. Compare each local ref with its fetched full SHA before adoption or ticket work. Create a missing local branch from that verified remote commit, or fast-forward a behind local branch after the clean-worktree check. On any other mismatch, stop adoption and publication, preserve both tips, and inspect the local and remote changes. Integrate retained work using rebase, review and validate the resulting layers, and refresh their evidence before continuing. Record the validated local tips separately from the unchanged remote tips used by publication leases. Require fetched remote commits to remain ancestors of the integrated local result so a valid lease cannot discard remote work. Missing evidence blocks continuation.

For a multi-ticket continuation, inspect the shared local catalog at the Git common directory's `gh-stack` path before initializing. On continuation, reuse an existing tracked stack only after its repository, trunk, branch order, saved parent boundaries, and PR identities match the recorded continuation evidence. Check out the verified layer being resumed instead of calling `init` again. If tracking is stale, follow [local catalog recovery](stack-recovery.md#rebuild-local-tracking); if it is conflicting or cannot be verified, stop and preserve it. The [init implementation](https://github.com/github/gh-stack/blob/v0.2.1/cmd/init.go#L281) rejects already-tracked branches.

When a verified multi-ticket continuation has no local tracking, adopt its existing remaining branches bottom to top with `gh stack init --base main "<bottom-remaining-branch>" ... "<top-remaining-branch>"`. Before initializing, set `git config --local rerere.enabled true` to avoid the [first-run confirmation](https://github.com/github/gh-stack/blob/v0.2.1/skills/gh-stack/references/commands.md#init). For a single ticket, resume its verified ordinary branch without stack commands.

Resume the [ticket workflow](../SKILL.md#steps) only after branch refs, validation evidence, and applicable local tracking are verified. Restack before continuing when main or a parent has changed.
