# Media delivery

Media makes committed wallpaper assets and current Profile pictures available to readers. Producers own the immutable bytes; Media owns its delivery catalog.

## Language

**Delivery catalog**:
Media's local record of which originals, variants, and Profile pictures can be delivered.

**Original**:
The immutable wallpaper asset accepted by Wallpaper Ingestion.

**Variant**:
An immutable rendition produced by Wallpaper Variant Generation for an existing wallpaper.

**Current picture**:
The Profile picture identified by the latest accepted Profile snapshot and still permitted by User's origin availability decision.

**Availability announcement**:
Media's statement that an image rendition has entered its delivery catalog.
