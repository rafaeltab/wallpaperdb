---
title: Getting started
description: The maintained local setup and contribution guide.
---

Follow [CONTRIBUTING.md](https://github.com/rafaeltab/wallpaperdb/blob/main/CONTRIBUTING.md) for prerequisites, authentication setup, worktree configuration, and verification.

Run `make help` for available commands and your worktree's ingress address. Service URLs use that ingress; fixed localhost ports copied from older guides may belong to another worktree.

For orientation, read the [context map](https://github.com/rafaeltab/wallpaperdb/blob/main/CONTEXT-MAP.md) and the README of the workspace you are changing. Use the [coding standards index](https://github.com/rafaeltab/wallpaperdb/blob/main/CODING_STANDARDS.md) to select relevant guidance.

Upgrading an existing installation also requires the [service upgrade procedures](/docs/guides/service-upgrades). Existing MinIO objects need a separate [storage migration](/docs/infrastructure/seaweedfs#existing-minio-data).
