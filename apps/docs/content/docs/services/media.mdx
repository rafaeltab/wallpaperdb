title: Media Service
description: Wallpaper and Profile picture delivery with an event-fed catalog
---

Media serves original wallpapers, resized renditions, and current Profile pictures from private object storage. It owns a PostgreSQL delivery catalog populated by Ingestor, Variant Generator, and User events.

## Delivery

`GET /wallpapers/:id` accepts optional `w`, `h`, and `fit=contain|cover|fill`. The default dimension limits are 7680 by 4320. Contain preserves aspect ratio within the requested box; cover crops; fill stretches. Contain and cover do not enlarge.

For resizing, Media chooses the smallest variant meeting both effective dimensions. An omitted dimension uses the original dimension for selection. A missing variant object falls back to the original. Technical storage failures return uncached 503; a missing original returns 404. Invalid query parameters return 400. Errors use RFC 9457 Problem Details with safe public messages.

Successful delivery has `Cache-Control: public, max-age=31536000, immutable`. Original wallpaper bodies stream from storage. Resized output runs through bounded Sharp child processes that can be terminated on cancellation.

`GET /profile-pictures/:pictureId` and HEAD consult User's authenticated availability endpoint on every origin request. Failed authority checks fail closed. Successful picture bodies are fully read under a byte limit before immutable caching is enabled. User owns retirement and storage retention; an already cached immutable copy cannot be recalled.

## Catalog and events

Media consumes `wallpaper.uploaded`, `wallpaper.variant.uploaded`, and Profile snapshots. Wallpaper catalog changes, occurrence acceptance, logical target acceptance, and availability publication intent commit in one PostgreSQL transaction. An outbox publishes availability events with stable CloudEvent and NATS identities, then records PubAck completion. Delivery remains at least once across the database and broker.

Current events identify immutable assets by their producer and logical ID. The catalog adapter resolves the producer's immutable storage descriptor before opening its PostgreSQL transaction. A missing or unavailable descriptor leaves the occurrence unprocessed for retry. Retained events containing bucket/key coordinates continue using their recorded location.

Variants arriving before their parent remain stored; their availability publication waits for that parent. Profile heads advance by producer version, while late picture metadata remains useful. Legacy assets retain their committed metadata and identity during reconciliation.

Consumers allow three processing attempts. Invalid or exhausted inputs require durable quarantine acceptance before acknowledgement. The file-backed `MEDIA_QUARANTINE` stream retains records for thirty days, has a one-GiB capacity, and rejects new writes when full. Failed quarantine writes leave source inputs pending.

Apply generated database migrations before deployment. Legacy consumers with recorded redeliveries can require coordinated recovery with all Media replicas stopped. The service README contains the retained-work recovery procedure; do not purge source streams.

## Effect boundaries and operations

Application modules own delivery, catalog, and availability ports. Adapters own PostgreSQL, S3, NATS, and native image workers. Fastify translates Effect outcomes into HTTP responses; one scoped runtime owns application resources. Deploy the complete `dist` directory, including deferred chunks and `resize-worker.mjs`.

`GET /health` checks dependencies and background workers. Unhealthy responses use status 503. `GET /ready` reports initialization and shutdown state. Wallpaper delivery alone does not establish that background ingestion is healthy.

Telemetry starts before instrumented application imports. The owned OpenTelemetry providers export SDK and Effect spans, structured logs, and metrics. Delivery, database, storage, resize, consumer, and publication measurements retain their diagnostic context.

## Development and verification

```sh
make infra-start
make migrate PACKAGE=media
make dev PACKAGE=media
make check PACKAGE=media
make test-focused PACKAGE=media
make check-crap PACKAGE=media CRAP_THRESHOLD=30
```

Worktree ingress and dependency ports come from the generated environment. Set `USER_SERVICE_URL` and the shared `USER_MEDIA_SERVICE_TOKEN` for Profile delivery. Storage credentials should grant read access to the required private asset buckets and `ASSET_REFERENCE_BUCKET`, which defaults to `asset-references`. Restrict quarantine access because it retains original event bytes.

Tests cover delivery policy, decoded image behavior, real PostgreSQL/S3/NATS contracts, replay and legacy recovery, HTTP cancellation and shutdown, emitted build artifacts, and production telemetry wiring.
